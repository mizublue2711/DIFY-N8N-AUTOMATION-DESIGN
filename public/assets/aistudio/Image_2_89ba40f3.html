GIAI ĐOẠN 1: GIA CỐ HẠ TẦNG & n8n

Mục tiêu: Đảm bảo VPS không crash OOM khi load model

ƯU TIÊN 1
1. Tạo Swap Space 8GB trên VPS Sống còn

Chạy lệnh cấp phát swap đệm để ArtCraft nạp model mà không tràn RAM 4GB:

fallocate -l 8G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
2. Tạo Thư Mục Đệm Buffer I/O Local
mkdir -p /tmp/artcraft_buffer && chmod 777 /tmp/artcraft_buffer
3. Khóa Chặt Concurrency Trên n8n Safe Rule

Vào Settings Workflow n8n ➔ Bật Concurrency Control ➔ Set Limit Concurrent Executions = 1.

🎯
